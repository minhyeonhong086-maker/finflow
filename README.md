# FinFlow 💰

> 개인 수입·지출과 월 예산을 한눈에 관리하는 반응형 웹 가계부

월세, 구독료, 생활비처럼 흩어져 있던 지출을 한곳에서 기록하고, 예산 대비 얼마나 썼는지 차트로 확인할 수 있는 서비스입니다.

- **배포 주소:** (배포 후 추가)

## 주요 기능

| 화면 | 기능 |
|---|---|
| 대시보드 | 이번 달 수입·지출·예산 사용률·남은 생활비, 카테고리별 지출 도넛 차트, 최근 6개월 지출 막대그래프, 최근 거래, 카테고리 예산 현황 |
| 수입·지출 | 거래 등록·수정·삭제, 수입/지출 구분 필터, 카테고리 필터, 메모 검색, 합계 자동 계산 |
| 예산 관리 | 월 전체 예산 및 카테고리별 예산 설정, 사용률 표시, 80% 이상 주의·초과 시 경고, 지난달 예산 불러오기 |
| 공통 | 월 이동, 브라우저 자동 저장(새로고침해도 유지), PC·태블릿·모바일 반응형, 예시 데이터 복원·전체 삭제 |

## 기술 스택

- **React 19** – 화면 구성
- **Vite** – 개발 서버 및 빌드
- **SVG 직접 구현** – 도넛 차트, 막대그래프 (차트 라이브러리 없이 구현)
- **localStorage** – 브라우저 데이터 저장
- **CSS (Media Query)** – 반응형 디자인

## 실행 방법

```bash
npm install     # 필요한 패키지 설치 (처음 한 번)
npm run dev     # 개발 서버 실행 → http://localhost:5173
npm run build   # 배포용 파일 생성 (dist 폴더)
```

## 폴더 구조

```
src/
├─ App.jsx              # 전체 화면 배치, 데이터 상태 관리, 메뉴 이동
├─ main.jsx             # 앱 시작점
├─ styles.css           # 전체 디자인
├─ pages/               # 메뉴별 화면
│  ├─ Dashboard.jsx
│  ├─ Transactions.jsx
│  └─ Budget.jsx
├─ components/          # 여러 화면에서 쓰는 부품
│  ├─ Sidebar.jsx, StatCard.jsx, ProgressBar.jsx, Icon.jsx
│  ├─ DonutChart.jsx, BarChart.jsx
│  └─ TransactionForm.jsx
├─ data/
│  ├─ storage.js        # 저장소 (나중에 서버 API로 교체 가능)
│  ├─ sampleData.js     # 가상 예시 데이터
│  └─ categories.js     # 카테고리·색상
└─ utils/               # 날짜·금액 계산 함수
```

## 참고

- 화면의 모든 금액과 거래 내역은 **가상의 예시 데이터**입니다.
- 데이터는 사용자의 브라우저에만 저장되며 서버로 전송되지 않습니다.
